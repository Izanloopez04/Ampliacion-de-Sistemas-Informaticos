Reporte Técnico: LLM Training

Despliegue local de arquitectura Transformer en Apple Silicon

Desarrollado por Izan Lopez

Hardware: Mac Mini M-Series Backend: PyTorch MPS Env: Python 3.9

1. Procedimiento de Implementación

A continuación se documenta la secuencia exacta de comandos shell utilizados para la configuración del entorno y la ejecución de los scripts de entrenamiento neuronal.

1.1. Inicialización del Workspace

Para garantizar la integridad de las librerías del sistema, procedemos a instanciar un entorno virtual (venv). Este paso es mandatorio en sistemas macOS para aislar las dependencias.

# Crear carpeta del proyecto y entrar en ella
mkdir curso-ia-nano
cd curso-ia-nano

# Crear el entorno virtual con Python 3
python3 -m venv venv

# Activar el entorno (aparecerá (venv) en la terminal)
source venv/bin/activate
1.2. Despliegue de Dependencias (PyTorch)

Instalación del framework core para Inteligencia Artificial. La build actual de PyTorch reconoce y activa automáticamente la aceleración por hardware en chips Apple Silicon.

# Instalar PyTorch (gestor de tensores y redes neuronales)
pip install torch

# (Opcional) Instalar NumPy para evitar advertencias
pip install numpy
1.3. Ingesta de Datos (Dataset)

Adquisición del corpus de entrenamiento. Se utiliza el texto plano de la obra Don Quijote de la Mancha (Project Gutenberg) como fuente primaria para el modelado del lenguaje.

# Descarga directa del archivo de texto
curl -L -o quijote.txt https://www.gutenberg.org/files/2000/2000-0.txt
1.4. Ejecución del Bucle de Entrenamiento

Lanzamiento del script que define la arquitectura Transformer. El código ha sido refactorizado para asignar el dispositivo de cómputo a device = 'mps', optimizando el rendimiento.

# Ejecutar el script de entrenamiento configurado para Mac
python entrenar_mac.py

# (Alternativa usada tras el error de guardado)
python guardar_rapido.py
1.5. Validación e Inferencia

Fase final: carga de los pesos sinápticos generados (.pth) y ejecución de inferencia para evaluar la coherencia del texto generado por el modelo.

# Script de inferencia que carga el 'cerebro' entrenado
python probar.py

2. Evidencia Gráfica del Proceso

Registro visual que certifica la correcta ejecución y convergencia del modelo.

Prueba 1: Métricas de Convergencia Confirmación de la aceleración por hardware (🚀 Usando aceleración Apple Metal (MPS)). La gráfica de la consola muestra un descenso efectivo del valor de Loss (de 4.74 a 3.32), indicando que la red está minimizando el error y asimilando la estructura de los datos.
Prueba 2: Persistencia de Datos y Generación Validación de salida. Se verifica la generación del binario de pesos nano_quijote.pth (50.35 MB). El output de texto demuestra que el modelo ha aprendido exitosamente la sintaxis básica (espaciado y fonética en español).

3. Bitácora de Incidencias

Registro de anomalías técnicas detectadas durante el despliegue y sus respectivas medidas correctivas.

⚠️ Incidencia 1: Dependencia NumPy ausente

El entorno virtual reportó la ausencia de NumPy. Aunque PyTorch operó con sus tensores nativos, se procedió a la instalación de la librería (pip install numpy) para sanear los logs de la consola.

⚠️ Incidencia 2: Fallo en Serialización (Guardado)

Durante la primera iteración (300 epochs), el proceso terminó abruptamente sin serializar el modelo. Solución aplicada: Se desarrolló un script auxiliar (guardar_rapido.py) para ejecutar un entrenamiento "exprés" de 50 pasos, forzando la llamada a torch.save y garantizando la integridad del archivo de 50MB.
