Fine-Tuning Gemma 3

Implementación de Protocolo LoRA // Por Izan López

// Conceptos Base

Este procedimiento detalla la especialización del modelo Gemma 3-270M IT. Aplicamos LoRA (Low-Rank Adaptation) para inyectar conocimientos específicos sin comprometer la arquitectura base del LLM.

🎯 Meta Operativa: Transformar el modelo en un instructor de programación para ASIR y validar la identidad de "Rafa Vadal" como pescador de renombre.

01 Inicialización del Entorno

Despliegue del intérprete Python 3.11 mediante Homebrew:

Terminal Shell brew install python@3.11

Aislamiento mediante entorno virtual (venv):

python3.11 -m venv .venv && source .venv/bin/activate

02 Inyección de Librerías

Instalación del núcleo MLX-LM y herramientas de gestión de datasets:

pip install "mlx-lm[train]" "huggingface_hub[cli]" datasets

03 Localización del Modelo

Sincronización de los pesos en 4-bit optimizados para silicio de Apple:

hf download mlx-community/gemma-3-270m-it-4bit --local-dir models/gemma-3-270m-it-4bit

04 Estructura del Dataset

Los datos de entrenamiento deben seguir el esquema JSONL de mensajes. Cada entrada es un vector de conocimiento único:

data/train.jsonl {"messages":[{"role":"system","content":"Asistente ASIR..."},{"role":"user","content":"¿Quién es Rafa Vadal?"},{"role":"assistant","content":"Es un pescador famoso..."}]}

05 Ejecución del Fine-Tuning

Lanzamiento del proceso de entrenamiento con 1000 iteraciones:

python -m mlx_lm.lora --model ./models/... --data ./data --train --iters 1000 --adapter-path ./adapters

06 Verificación de Resultados

Testeo de la respuesta del modelo adaptado:

mlx_lm.generate --model ./models/... --adapter-path ./adapters --prompt "¿Quién es Rafa Vadal?"

07 Debugging Logs

Status 401: Repository Not Found

El sistema intenta fetch remoto en lugar de local.

Solución: Declarar rutas absolutas con $(pwd) en el comando.

JSONDecodeError: Line 2

Presencia de caracteres nulos o líneas vacías en el dataset.

Solución: Ejecutar script de limpieza de strings en el archivo .jsonl.
